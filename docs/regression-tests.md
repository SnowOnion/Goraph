# Goraph 回归测试用例

## 核心功能验证清单

### 1. 基础渲染
- [ ] 页面加载无 JS 报错
- [ ] 棋盘 Canvas 渲染正常（可见网格线、节点）
- [ ] 顶栏显示回合指示（黑棋/白棋）
- [ ] 操作栏按钮可见（PASS、悔棋、重来、设置）

### 2. 落子交互
- [ ] 点击棋盘空节点 → 棋子立即显示
- [ ] 落子后回合切换（黑→白→黑）
- [ ] 触摸拖动时预览环跟随手指
- [ ] 触摸松开时棋子落到最终位置
- [ ] 点击已占用节点 → 不落子，显示提示
- [ ] 不合规则落子（自杀）→ 显示提示，不落子

### 3. 虚手（PASS）
- [ ] 点击 PASS 按钮 → 显示"黑棋放弃一手"，回合切换
- [ ] 连续两次虚手 → 终局弹窗显示比分
- [ ] 终局后 PASS 按钮禁用

### 4. 悔棋
- [ ] 点击悔棋 → 撤销上一手，棋盘状态恢复
- [ ] 无历史时悔棋按钮禁用

### 5. 重启游戏
- [ ] 点击重来 → 棋盘清空，回合重置为黑棋
- [ ] 终局弹窗「再来一局」→ 清空棋盘开始新局
- [ ] 新局中 PASS 按钮恢复可用

### 6. 棋盘切换
- [ ] 点击棋盘选择器切换棋盘 → 棋盘形状变化
- [ ] 切换棋盘自动重置游戏状态
- [ ] 自定义棋盘带 ✏️ 标记

### 7. 设置面板
- [ ] 点击设置 → 面板从底部滑出
- [ ] 手数序号开关 → 棋子上显示/隐藏编号
- [ ] AI 对手开关 → 启用后 AI 自动落子
- [ ] 禁止全同再现开关 → 打劫规则生效
- [ ] 五子棋规则开关（仅矩形棋盘可见）
- [ ] 点击编辑器入口 → 跳转到编辑器页面

### 8. 编辑器
- [ ] 编辑器页面加载正常
- [ ] 加点工具：点击空白处添加节点
- [ ] 连线工具：依次点击两个节点创建边
- [ ] 移动工具：拖拽节点改变位置
- [ ] 删除工具：点击节点/边删除
- [ ] 清空按钮 → 删除所有节点和边
- [ ] 撤销/重做按钮正常工作
- [ ] 保存按钮 → 保存到 localStorage
- [ ] 加载按钮 → 加载已保存棋盘
- [ ] 导出 JSON → 复制到剪贴板
- [ ] 返回对弈 → 回到游戏页面

### 9. 移动端适配
- [ ] viewport 禁止缩放（双指/双击不放大）
- [ ] 触摸事件正常响应（无 300ms 延迟）
- [ ] 所有按钮可触摸点击
- [ ] 棋盘触摸拖动预览正常
- [ ] 安全区域适配（iPhone 刘海）
- [ ] 横屏时布局自适应

### 10. 自定义棋盘对战
- [ ] 编辑器创建棋盘后保存
- [ ] 对战页面出现自定义棋盘选项
- [ ] 选中自定义棋盘 → 加载到 Canvas
- [ ] 自定义棋盘上可正常落子、吃子
